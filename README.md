# e-plantShopping

## Paradise Nursery Shopping Application 

e-plantShopping is a React-based front-end shopping cart application for an online plant store called **Paradise Nursery**. The application allows users to browse a variety of house plants, add items to a shopping cart, manage quantities, and view the total cost before checkout.

### Features
- Landing page with company overview and Get Started button
- Product listing page with categorized house plants
- Add to Cart functionality with dynamic cart count
- Shopping cart page with:
  - Increase / decrease quantity
  - Delete items
  - Total item count and total cost
- Redux Toolkit for global state management
- React Hooks (`useState`, `useEffect`)
- Responsive UI

### Technologies Used
- React
- Redux Toolkit
- React Hooks
- JavaScript (ES6+)
- CSS

### Project Purpose
This project was built as part of a final lab to demonstrate practical skills in React component design, state management using Redux, and handling user interactions in a real-world shopping cart scenario.
